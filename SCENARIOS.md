# Scenario traceability

All 60 operations are implemented in the existing single-agent application.
The Tool column maps each scenario's service operation to its reusable LangChain
module tool. `get_employee` is also a dedicated compatibility tool. The generic
HTTP route is `POST /operations/{operation}` with `{"arguments": {...}}`.

Every state-changing operation returns a human confirmation proposal first; only
`POST /confirmations/{id}` can commit it after owner confirmation and revalidation.
"Pending" is a real persistent request, not automatic approval or fulfillment.
All 60 have service tests; this does not claim 60 natural-language live LLM tests.
See README for exact local policies and intentional fulfillment limitations.
